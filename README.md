# PlanesPro Final

**Landing page de captación de clientes para PlanesPro.cl**

---

## Por qué existe este proyecto

En Chile, elegir el plan de salud correcto es una decisión compleja. Miles de personas pagan más de lo necesario en su Isapre, o tienen coberturas que no se ajustan a su realidad.

**PlanesPro** nació para resolver esto: ofrecer asesoría experta y personalizada que ayuda a las personas a optimizar su plan de salud, ya sea cambiándose de Isapre o ajustando su plan actual.

Esta landing page es el primer punto de contacto con potenciales clientes. Su objetivo es simple:

> **Convertir visitantes en leads calificados.**

---

## Qué hace esta landing

1. **Comunica la propuesta de valor** de forma clara y directa
2. **Genera confianza** a través de testimonios, social proof y logos de Isapres
3. **Segmenta perfiles** (Joven, Familia, Freelance, etc.) para conectar con cada visitante
4. **Captura información de contacto** para iniciar el proceso de asesoría

---

## Para quién está diseñada

| Perfil | Dolor Principal |
|--------|-----------------|
| **Joven profesional** | Paga mucho por coberturas que no usa |
| **Familia** | Necesita mejor cobertura para hijos |
| **Freelancer** | No sabe qué plan elegir sin empleador |
| **Embarazada** | Busca la mejor cobertura para maternidad |
| **Cotizante sobre 50** | Preocupado por el 7% y coberturas futuras |

---

## Secciones de la landing

- **Hero:** Propuesta de valor + CTA principal
- **Proceso:** Cómo funciona la asesoría (4 pasos simples)
- **Planes:** Perfiles de usuario con recomendaciones
- **Social Proof:** Testimonios y logos de Isapres
- **CTA Final:** Formulario de contacto
