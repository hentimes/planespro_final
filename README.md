# PlanesPro Final

Proyecto de landing page optimizada para PlanesPro.cl - Asesoría experta en planes de Isapre.

## Arquitectura

Este proyecto sigue estrictamente las reglas definidas en `ARCHITECTURE.md`.

## Estructura

Ver `ARCHITECTURE.md` para la estructura completa de directorios y reglas de desarrollo.

## Desarrollo

- **Rama principal:** `main` (protegida)
- **Rama de desarrollo:** `dev`

## Stack Tecnológico

- HTML5 semántico
- CSS3 (arquitectura de partials)
- JavaScript ES6+ (módulos)
- Sin frameworks (Vanilla JS)

## Inicio Rápido

1. Clonar el repositorio
2. Abrir `index.html` en un servidor local
3. Para desarrollo, trabajar en rama `dev`
